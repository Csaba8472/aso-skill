# OpenClaw Integration

The ASO skill is packaged as an OpenClaw workspace with specialized agents and full Python tools.

## Install

```bash
bash integrations/install-integrations.sh openclaw
```

This installs the workspace to `~/.openclaw/aso-skill/`.

## Usage

The agent is available by `agentId` in OpenClaw:
```
agentId: app-store-optimization
```
