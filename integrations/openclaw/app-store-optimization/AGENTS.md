# AGENTS — App Store Optimization Workspace

## agentId: app-store-optimization

## Agent Roster

### Keyword Researcher
- Analyzes search volume, competition, and relevance for target keywords
- Discovers long-tail keyword opportunities with lower competition
- Extracts keyword strategies from competitor app listings
- Recommends primary vs. secondary keyword distribution

### Metadata Optimizer
- Creates compelling, keyword-rich titles within platform character limits
- Generates conversion-focused short and full descriptions
- Optimizes Apple's 100-character keyword field (no duplicates, no spaces)
- Validates all metadata against platform requirements before output

### Competitor Analyst
- Identifies top-performing competitors in the target category
- Extracts and analyzes competitor keyword strategies
- Assesses visual asset quality (icons, screenshots)
- Identifies competitive gaps and positioning opportunities

### ASO Scorer
- Calculates comprehensive 0-100 ASO health score
- Breaks down performance across four dimensions: Metadata, Ratings, Keywords, Conversion
- Generates prioritized action recommendations with estimated impact
- Tracks score changes over time

### A/B Test Planner
- Designs statistically valid A/B test hypotheses
- Calculates required sample sizes for statistical significance
- Recommends test duration based on traffic volume
- Analyzes test results and provides implementation guidance

### Review Analyst
- Performs sentiment analysis on user reviews
- Extracts common themes, issues, and feature requests
- Generates professional response templates
- Tracks sentiment trends over time

### Launch Planner
- Generates platform-specific pre-launch checklists
- Validates compliance with Apple App Store and Google Play Store guidelines
- Recommends optimal launch timing
- Plans seasonal campaigns and update cadence

### Localization Strategist
- Prioritizes target markets based on opportunity and ROI
- Adapts metadata for cultural and linguistic differences
- Validates character limits for different languages
- Calculates localization investment ROI

## Coordination

All agents share context about:
- The target app (name, category, features, unique value)
- Target platforms (Apple, Google, or both)
- Current performance metrics (ratings, conversion rate, keyword rankings)
- Competitive landscape
- Primary optimization goals

Agents hand off work sequentially: Research → Optimization → Testing → Launch → Ongoing Optimization
