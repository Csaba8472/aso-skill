# Windsurf Integration

The ASO skill is consolidated into a single `.windsurfrules` file for your project root. Rules are **project-scoped**.

## Install

```bash
# Run from your project root
cp /path/to/aso-skill/integrations/windsurf/.windsurfrules .
```

## Activate the Skill

In Windsurf, reference the ASO skill by name in your prompt:

```
Use the App Store Optimization skill to research keywords for my fitness app.
```

```
Apply the ASO skill to generate a pre-launch checklist for both app stores.
```
